# Triple Espresso

# Es una página web para una cafetería y zona de estudio. El proyecto presenta información sobre la cafetería, como su horario, ubicación y enlaces de navegación, además de una sección para reservar una mesa y un pie de página con enlaces a redes sociales. La sección de reserva contiene un formulario en el que el usuario puede introducir su nombre, número de comensales, fecha y hora, y correo electrónico. También incluye una casilla para aceptar los términos de uso y un botón para enviar la reserva.

# El proyecto está desarrollado utilizando HTML5 y CSS3. En HTML se utilizan etiquetas semánticas como header, nav, main, section, form, footer, ul y li para organizar correctamente el contenido de la página. El formulario utiliza diferentes tipos de campos, como text, number, datetime-local, email y checkbox, junto con atributos required, placeholder y name. En CSS se utilizan Flexbox y posicionamiento relativo y absoluto para organizar y posicionar los diferentes elementos de la página. También se utilizan propiedades como background, padding, margin, max-width, border-radius, z-index y box-sizing para conseguir el diseño indicado. Se utilizan las fuentes Inter y Noto Serif, obtenidas mediante Google Fonts. También se implementan estados :hover y transiciones para los enlaces de navegación, el botón de reserva y los enlaces de redes sociales.
